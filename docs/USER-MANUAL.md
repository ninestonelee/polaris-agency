## 1. 시작하기

### 1.1 가입 (2분)

1. 홈페이지에서 **"지금 시작하기"** 클릭
2. 이메일 & 비밀번호 입력 (구글/카카오 로그인도 지원)
3. 온보딩 시작

### 1.2 온보딩 7단계 (5분)

| 단계 | 내용 | 팁 |
|------|------|-----|
| 1단계 | 환영 | 그냥 "시작하기" 누르세요 |
| 2단계 | 업종 선택 | 5개 템플릿 중 선택하면 미션/톤이 자동 채워짐 |
| 3단계 | 회사 정보 | 회사명·미션·톤 입력 (나중에 변경 가능) |
| 4단계 | API 키 입력 | OpenAI 또는 Anthropic 키 (최소 1개 필수) |
| 5단계 | 첫 직원 고용 | 8명 중 원하는 직원 클릭 |
| 6단계 | 샘플 작업 | 자동 실행 — AI 결과물을 바로 확인 |
| 7단계 | 완료! | 대시보드로 이동 |

### 1.3 업종별 추천 템플릿

| 업종 | 아이콘 | 자동 설정되는 미션 | 톤 |
|------|--------|-------------------|-----|
| 온라인 쇼핑몰 | 🛍️ | 합리적 가격의 좋은 제품을 추천한다 | 친근하고 신뢰감 있게 |
| 카페·식음료 | ☕ | 단골 손님과의 일상적 소통 | 따뜻하고 캐주얼하게 |
| 학원·교육 | 📚 | 학생의 성장에 책임진다 | 전문적이고 따뜻하게 |
| 병원·의료 | 🏥 | 환자의 불안을 줄이는 의료 정보 | 정중하고 정확하게 |
| 제조·B2B | 🏭 | 품질과 납기를 약속한다 | 신뢰감 있고 전문적으로 |

> 💡 "기타"를 선택하면 미션과 톤을 직접 입력할 수 있습니다.

## 2. 대시보드 가이드

### 2.1 구성 요소

```
┌──────────────────────────────────┐
│ ⭐ 폴라리스 에이전시              │ 대시보드 | 직원 | 설정 | 도움말 | 로그아웃
├──────────────────────────────────┤
│  오늘 사용량    │  이번 달 누적   │
│  ₩1,200 ↑30%  │  ₩45,000       │
│  5회 · 3,200토큰│  127회 · 89K토큰│
├──────────────────────────────────┤
│  일별 사용량 차트 │ 모델별 파이차트 │
├──────────────────────────────────┤
│  고용된 AI 직원                   │
│  [마케터 루나] [작가 노바] [CEO 폴라] [편집자 시리우스] │
└──────────────────────────────────┘
```

### 2.2 사용량 카드

- **오늘 사용량**: 오늘 하루 동안의 비용 (원화), 작업 횟수, 토큰 수
- **어제 대비**: ↑ / ↓ 퍼센트로 증감 표시 (빨강=증가, 초록=절약)
- **이번 달 누적**: 월 초부터 오늘까지 누적

### 2.3 차트

- **일별 막대차트**: 최근 30일간 일별 사용 비용
- **모델별 파이차트**: GPT-4o / Claude Sonnet / Haiku 등 모델별 비용 비중

### 각 직원 상세 프로필

#### ⭐ CEO 폴라 — 전략·비전·의사결정

**이럴 때 쓰세요:**
- 다음 분기 전략을 고민할 때
- 사업 방향 피벗을 검토할 때
- KPI를 설정하거나 재검토할 때

**샘플 프롬프트:**
```
다음 분기 우리 회사의 핵심 KPI 3개를 제안해줘
```

**고급 프롬프트:**
```
우리 회사 현황:
- 업종: 온라인 쇼핑몰 (패션)
- 월매출: 3,000만원
- 직원: 나 포함 3명
- 고민: 마진율이 15%로 낮음

질문:
1. 다음 분기에 집중해야 할 핵심 지표 3개
2. 각 지표를 개선할 구체적 액션 플랜
3. 리스크 요소와 대비책
```

```
인스타그램 피드 포스팅을 3가지 톤으로 작성해줘:
1. 감성적·감각적 (2030 여성 타겟)
2. 건강·웰빙 (4050 주부 타겟)
```

## 4. 작업 실행 방법

### 4.1 기본 흐름

1. **직원 페이지**에서 원하는 직원 클릭 (또는 대시보드에서 바로 클릭)
2. **프롬프트 입력** — 시키고 싶은 일을 자유롭게 입력
3. **"시키기" 버튼** 클릭
4. **실시간 응답** 확인 (글자가 타이핑되듯 나타남)
5. 완료 후 **비용·토큰·소요시간** 확인

### 4.2 좋은 프롬프트 작성법

| 요소 | 나쁜 예 | 좋은 예 |
|------|---------|---------|
| 구체성 | "글 써줘" | "카페 신메뉴 홍보 인스타 카피 3개 써줘" |
| 맥락 | "마케팅해줘" | "우리 카페(을지로, 2030 타겟)의 여름 신메뉴 마케팅 기획안" |
| 형식 | (미지정) | "표로 정리해줘" / "1,2,3 번호를 매겨줘" |
| 톤 | (미지정) | "MZ세대가 좋아할 캐주얼한 톤으로" |
| 분량 | (미지정) | "500자 이내로" / "A4 1장 분량으로" |

### 4.3 프롬프트 길이 제한

- 최대 **10,000자**까지 입력 가능
- 긴 원문을 붙여넣고 요약/편집을 시킬 수 있음

### 4.4 결과물 활용

- 결과 텍스트를 **복사**하여 SNS/블로그/이메일에 바로 붙여넣기
- 마음에 안 들면 프롬프트를 수정하고 **다시 시키기**
- 여러 직원에게 같은 주제를 시켜서 **비교** 후 선택

## 5. 설정 관리

### 5.1 API 키 변경/추가

**경로**: 상단 메뉴 → **설정**

- OpenAI API 키: GPT-4o, GPT-4o-mini 모델 사용
- Anthropic API 키: Claude Sonnet, Claude Haiku 모델 사용
- 최소 1개는 등록해야 작업 실행 가능
- 두 개 모두 등록하면 모든 직원 사용 가능

### 5.2 키 발급 방법

**OpenAI:**
1. https://platform.openai.com/api-keys 접속
2. "Create new secret key" 클릭
3. `sk-`로 시작하는 키 복사

**Anthropic:**
1. https://console.anthropic.com 접속
2. API Keys 메뉴에서 새 키 생성
3. `sk-ant-`로 시작하는 키 복사

### 5.3 보안

- 키는 **본인 계정에만** 저장됩니다
- 다른 사용자는 접근 불가 (Row Level Security 적용)
- 키는 서버에서만 사용되고 브라우저에 노출되지 않습니다

## 6. 비용 안내

### 6.1 폴라리스 에이전시 이용료

**폴라리스 에이전시 자체는 무료입니다.** AI 모델 사용료(OpenAI/Anthropic)만 본인 계정에서 직접 과금됩니다.

### 6.2 AI 모델별 예상 비용 (원화)

| 모델 | 사용 직원 | 짧은 작업 (카피 1개) | 중간 작업 (블로그 글) | 긴 작업 (보고서) |
|------|----------|-------------------|---------------------|-----------------|
| GPT-4o | 폴라, 시리우스, 알타이르, 카펠라 | ~₩50~200 | ~₩300~1,500 | ~₩1,000~5,000 |
| Claude Sonnet | 루나, 노바, 베가 | ~₩80~300 | ~₩500~2,000 | ~₩1,500~7,000 |
| Claude Haiku | 미라 | ~₩10~50 | ~₩50~200 | ~₩100~500 |

### 6.3 비용 절약 팁

1. **간단한 작업은 미라(Haiku)에게**: FAQ, 짧은 응대 메시지는 미라가 가장 저렴
2. **프롬프트를 구체적으로**: 재작업 횟수를 줄여 비용 절감
3. **대시보드 모니터링**: 일별 사용량 차트로 비용 추세 확인
4. **모델별 파이차트 확인**: 비싼 모델에 작업이 몰리면 역할 재배분

### 6.4 비용 계산 공식

```
비용(₩) = (입력 토큰 수 ÷ 1,000,000 × 입력 단가) + (출력 토큰 수 ÷ 1,000,000 × 출력 단가)
         × 환율(1,350원/달러)
```

> 참고: 한글 1글자 ≈ 2~3토큰, 영어 1단어 ≈ 1토큰

## 7. 실무 활용 시나리오

### 시나리오 1: 온라인 쇼핑몰 — 주간 콘텐츠 루틴

**월요일 — 주간 기획 (CEO 폴라)**
```
이번 주 프로모션 주제는 "봄맞이 새학기 특가"야.
월~금 SNS 콘텐츠 캘린더를 짜줘.
각 날짜별 주제, 포맷(릴스/피드/스토리), 핵심 메시지 포함.
```

**화~목 — 콘텐츠 제작 (마케터 루나)**
```
수요일 릴스용 스크립트를 써줘.
주제: 새학기 가방 3종 비교
형식: 15초 분량, 훅→본론→CTA
톤: 밝고 에너지 있게
```

**금요일 — 주간 리뷰 (분석가 카펠라)**

## 9. 고급 활용법

### 9.1 체이닝 (직원 릴레이)

하나의 작업을 여러 직원에게 순차적으로 시키는 전략:

```
1단계: CEO 폴라 → "신제품 마케팅 전략 3가지 제안해줘"
2단계: 마케터 루나 → "1번 전략(감성 브랜딩)으로 인스타 카피 5개 써줘"
3단계: 편집자 시리우스 → "위 카피 중 3번을 더 세련되게 다듬어줘"
4단계: 디자이너 베가 → "이 카피에 어울리는 배너 컨셉 제안해줘"
```

### 9.2 AB 테스트

같은 주제를 다른 직원(또는 다른 프롬프트)으로 비교:

```
루나에게: "이번 할인 이벤트를 MZ 감성으로 써줘"
노바에게: "이번 할인 이벤트를 스토리텔링 방식으로 써줘"
→ 두 결과를 비교해서 더 나은 것 선택
```

### 9.3 템플릿 프롬프트 만들기

자주 쓰는 요청은 메모장에 저장해두고 변수만 바꿔 사용:

```
[템플릿: 주간 인스타 캘린더]
이번 주 프로모션: {주제}
기간: {월}~{금}
타겟: {타겟층}

월~금 인스타 콘텐츠 캘린더:
- 각 날짜별 주제
- 포맷 (릴스/피드/스토리)
- 핵심 메시지 1줄
- 해시태그 5개
```

### 9.4 장문 입력 활용

프롬프트에 최대 10,000자까지 넣을 수 있으므로:
- 기존 글을 붙여넣고 "이걸 다듬어줘"
- 회의록을 붙여넣고 "핵심 3줄 요약해줘"
- 경쟁사 소개를 붙여넣고 "우리랑 차별화 포인트 분석해줘"

### 9.5 비용 최적화 전략

| 목적 | 추천 직원 | 이유 |
|------|----------|------|
| 대량 반복 (FAQ 50개) | 미라 (Haiku) | 건당 ₩10~50, 50건 = ₩500~2,500 |
| 초안 빠르게 | 미라 → 시리우스 | 미라로 싸게 초안, 시리우스로 마무리 |
| 품질 중시 (제안서) | 알타이르/노바 (Sonnet) | 좋은 모델로 한 번에 |
| 전략/분석 | 폴라/카펠라 (GPT-4o) | 복잡한 추론은 4o가 강점 |

## 10. FAQ & 문제 해결

### Q1. API 키는 어디서 받나요?

**OpenAI**: https://platform.openai.com/api-keys → "Create new secret key"
**Anthropic**: https://console.anthropic.com → API Keys → 새 키 생성

### Q2. 비용이 얼마나 나올까요?

- SNS 카피 1개: ₩50~300
- 블로그 글 1편: ₩300~2,000
- 주 5일 × 하루 3작업 기준: 월 ₩15,000~50,000 예상

### Q3. 한국어를 잘 이해하나요?

모든 직원이 한국어에 최적화되어 있습니다. 회사 미션과 톤이 시스템 프롬프트에 자동 반영되어 일관된 한국어 결과를 제공합니다.

### Q4. 내 데이터는 안전한가요?

- API 키: 본인 계정에만 저장 (RLS 보호)
- 작업 내용: 본인만 조회 가능
- 외부 전송: OpenAI/Anthropic API로만 전달 (이들의 개인정보 정책 적용)

### Q5. 특정 직원이 "API 키를 먼저 등록해주세요"라고 하면?

- OpenAI 직원 (폴라, 시리우스, 알타이르, 카펠라): OpenAI 키 필요
- Anthropic 직원 (루나, 노바, 베가, 미라): Anthropic 키 필요
- **설정** 페이지에서 해당 키를 추가 등록하세요

### Q6. 온보딩 중 "예상치 못한 문제" 에러가 뜨면?

1. 브라우저 개발자도구(F12) → Console에서 에러 메시지 확인
2. 가장 흔한 원인: API 키가 유효하지 않음
3. 해결: 설정 → API 키 재입력 또는 새 키 발급

### Q7. 응답이 중간에 끊기면?

- "다시 시도" 버튼 클릭
- 네트워크 연결 확인
- API 키 잔액 확인 (OpenAI/Anthropic 대시보드)
